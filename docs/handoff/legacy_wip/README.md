# 历史工作副本备份

本目录保留迁移前另外两个工作副本的未提交改动，不参与当前运行时导入。

- `recovery/`：原 `training/recovery-ppo-20261013` 工作副本的修改补丁及尚未提交的窄道实验、说明和诊断源码。
- `localization/`：原 `fix/localization-mapping-20261015` 工作副本的修改补丁，以及与当前工作区不同的未跟踪文件。与当前树完全相同的 3,020 个新文件没有重复保存。

每个 `MANIFEST.json` 记录源分支、基准提交、文件哈希；`tracked_changes.patch` 相对该基准生成。当前可运行实现已经在仓库根目录的 `training/`、`models/` 中。不要把旧补丁直接套到最新源码，也不要把目录内旧报告视作当前模型成绩。

如需还原旧实验，先在独立工作树检出对应 `base_commit`（浅克隆需额外取回该历史提交），再应用该目录中的补丁，并将 `new_files/` 按相对路径复制进去。源工作副本、当前模型及部署包没有被改写。
