## 本项目已有证据

同一个actor、原安全层，15厘米总余量直线窄道单种子：圆形几何行驶0米；矩形网格采样0米；矩形加单元内位置细化0.746米，三者均超时、无碰撞。细化版658帧报路线不完整。数据见 `NARROW_PASSAGE_COMPARISON_20261013.json`。这不足以证明单纯增加角速度档就能修复问题。

当前非零角速度只有±0.5 rad/s，0.2秒控制周期的一步理想转角约5.73°，说明精细动作值得测试；实际转角仍由动力学决定，低速转向是否克服固件死区需要另行标定。

## 调整后的验证顺序

1. **几何及运动可行性先独立验证。** 不能将二维可通行或存在某种朝向当作当前姿态可执行；完整段扫掠、转角和初始姿态都要检查。保留未知占据、安全边距及激光安全检查。
2. **修复状态表达，而非宣布路线安全。** 区分静态通道存在、当前姿态待对齐、扫描／定位不支持、真实堵塞等原因。保留对齐信息不等于允许继续使用未经当前扫描验证的旧路线。如何保留局部目标仍是本项目工程假设，需要单独试验。
3. **动作空间单独对比。** 原动作、增加小角速度档、几何改动及两者结合分别测试同一组冻结入口场景；扩展模型、掩码、速度探测和部署合同，不能直接改写旧actor的动作。建议数值属于候选，不是论文结论。
4. **激光局部通道观测。** 输出左右墙距、相对航向、可用宽度与检测置信度供模型选择动作。缺墙、开口、玻璃／异常返回、遮挡都不能强制居中。局部横向控制不能替代全局沿通道方向定位。
5. **闭环合格后再训练。** 先15厘米，再12.5厘米，最后10厘米。增加入口偏角、横向偏移、地图网格相位、短时阻挡和扫描恢复的独立场景；分别记录成功、碰撞、误停车、最小墙距、控制耗时。PPO仍可保留，不能因某篇论文用SAC就直接换算法。

10厘米总余量扣除现有每侧4厘米边距后，每侧仅剩1厘米误差预算。理想仿真墙体在5毫米栅格上可以通过直线几何检查，但提高地图分辨率不等于提高实车地图或定位精度。

参考Nav2仅用于方法、离线对照和验证设计；最终模型速度决策不必接入Nav2控制器或行为树。本轮为资料核对，未更改模型或启动训练。
