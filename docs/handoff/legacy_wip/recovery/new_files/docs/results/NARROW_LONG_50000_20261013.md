## 本轮变化

- 新动作先验扣分从1.0降至0.2；熵系数从0.01升至0.015。这是明确的探索配置变化，不能把任何改善全部归于增加步数。加载和导出验证确保新扣分保存后仍为0.2。
- 初期任务约20%简单宽空间回放、45%窄道出口短任务、35%完整穿越；20,000步后约20%简单回放、80%完整穿越。20%仅是本地图回放，不代表旧动态导航能力已经保护。
- 出口任务起点x=3.55–3.85米，y=2±0.005米，yaw±0.025rad，目标[4.55,2]。完整穿越起点x=1.15–1.65米，y=2±0.02米，yaw±0.08rad，目标[5,2]。物理重置沿用原有随机位姿误差；这些任务不改变实体墙面或雷达。
- 原直道奖励之外增加以局部子目标方向为依据的折扣势能差项，不使用真值避障或规定转向动作。终止时势能置零。本直道奖励与课程不能直接用作U形绕行或窄路口解决方案。
- 训练种子73123。每5,000步保存ZIP、进行5个固定开发任务评估；首次检查点同时评估旧12动作与调整后未继续训练的20动作，区分配置变化和学习效果。开发场景与训练种子不同，仍是重复开发集，不能充当最终独立验收。

## 低资源限制

后台服务：agv-narrow-long-50000-20261013.service。计算线程1；Nice=19、空闲IO优先级；MemoryHigh=2GiB、MemoryMax=4GiB、TasksMax=24。既有cgroup累计CPU限速服务agv-group-cpu-limit-20261012限制所有列入的训练／评估进程合计约0.5核；该机制不是50%整机占用。短时峰值不保证完全没有桌面影响。

剩余磁盘至少1GiB才允许启动，每100步检查剩余空间，低于512MiB保存检查点并停止。每5,000步保留一个ZIP；actor_latest.pt覆盖同一候选文件，最终portable包单独生成，原发布目录保留。

## 预计与验收

按之前1000步实测536秒估算，50,000步纯训练约7.5小时；加10轮评估及基准，预计约8–11小时，实际进度决定完成时间。更易成功的短任务可能缩短回合并改变速度，不能承诺精确结束时刻。

先看1万／3万／5万步是否逐步减少入口等待、增加完整安全到达。每轮3个完整窄道任务加2个简单任务只够开发检查；必须再进行更多种子、普通／动态回归、12.5/10厘米以及转角几何验证，才能判断部署。5万步不会保证成功或最优路径。
