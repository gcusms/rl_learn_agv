# 窄道与窄路口优化：2026-10-13

本轮是工程预检，尚未开始新的 PPO，也未证明窄道成功率提高。车身宽 0.329460022 米，窄道宽按车身加**总计**10、12.5、15厘米设置。保留每侧4厘米静态边距、原生停车保护、220束激光及0.2米/秒速度上限。

## 实际改动

| 项目 | 实现及边界 |
|---|---|
| 对齐信息 | AlignmentNarrowCore 区分完整运动可执行、初始车头需要对齐、几何或扫描阻塞。保留经检查的局部方向，但不会因此允许前进或声明路线完整。 |
| 精细动作 | 原12动作编号不变，增加纯转向±0.1、±0.2 rad/s，以及0.05、0.1 m/s配±0.1 rad/s，共20动作；仅进行原保护探测，旧actor未使用新增动作。 |
| 激光墙面 | 从当前扫描分离纵向墙面，再拟合宽度、方向、偏移及双侧距离。入口端墙不再直接与侧墙混合拟合。无支持证据返回零特征。 |
| 接口版本 | 新观测318维，旧300维前缀保留。旧模型仍为300维／12动作，不能直接作为新接口模型部署。 |
| 路口场景 | 三个宽度分别设紧直角口和扩大转角区，共6个实体MuJoCo场景。 |

## 验证与结果

15项单元检查通过，包括扫描缺失、入口端墙、陈旧扫描及里程计异常拒绝、探测不修改原保护状态、动作编号与接口、对齐状态和矩形扫掠。

6个实体XML均成功加载，起点矩形含边距均合法。三个紧直角口在交点原地转90度均不通过；三个扩大转角区均通过这项几何检查。**原地转向失败不能证明连续行驶转弯也不可行。** 现有线段加角点旋转表示可能保守拒绝曲线，不能靠无限增加PPO步数解决表示限制。

第一轮配对预检使用同一原发布actor、15厘米直道、同一种子，每版110步／22秒。原锚点版和保留对齐信息版均行驶0.746米后等待，无碰撞、无物理保护干预，未到达目标。新版本79帧为需初始对齐状态，22次额外探测中20次存在合法细动作，但旧actor仍只能选原12动作。因此**没有行驶效果提升证据**。

第一轮墙面特征22次均未识别。修正入口端墙分离后，独立入口扫描能识别两侧墙，估计宽约0.484米，对应物理宽约0.479米；只是一帧仿真扫描，不能视为实车厘米精度证明。第二轮短程复验结果见下列文件。

- 第一轮：training/runs/narrow_alignment_screen_20261013/RESULTS.json。
- 墙面修正后：training/runs/narrow_alignment_screen_v2_20261013/RESULTS.json。
- 独立入口原始扫描：[入口扫描记录](NARROW_ENTRANCE_SCAN_20261013.json)。近似入口姿态的独立重置，不是历史帧复现。
- 每轮源文件快照保存在source_snapshot；若执行期间追加测试使总哈希检查不一致，需逐项核对实际运行源码，不能忽略。

达到110步预检上限不是标准140秒评估超时；一个开发种子不是总体成功率。细动作仅探测，本实验未证明actor已学会使用。

实验服务纳入既有限速器，合计约半个CPU核，单进程内存上限8GiB，计算线程1。模型未替换。

## 下一步训练门槛

1. 显式适配318维／20动作的PPO actor、训练环境和导出运行时。单独保存新版本，记录迁移及优化器重置，验证采样动作与实际执行完全一致。当前只完成特征和动作探测接口，尚未完成actor迁移。
2. 先训练宽入口及15厘米直道中的细致对齐，随机化起点朝向与横向偏差，保留普通场景回放；使用独立训练种子。不能用等待惩罚强迫不安全前进。
3. 独立多种子比较完整穿越和最终安全到达，单独记录碰撞及保护干预，不能以多走几十厘米代替成功。
4. 再做12.5厘米、扩大转角区及连续转弯几何验证。紧直角口若仍全部被路线表示拒绝，不启动针对它的长PPO。
5. 10厘米余量仍受2厘米地图保守栅格量化影响，未获得通行保证。最后核验真实定位误差和低角速度响应；尚未做实车PID标定，小角速度可能受固件死区影响。

新源码均位于prototypes，未接入默认运行。尚未启动新的窄道PPO，原发布权重保留。

修正墙面分离后，连续轨迹的22次抽样均识别到纵向墙面（第一轮为0/22），20/22次有合法精细动作。实际旧actor行驶距离仍为0.746米，未到达，两个版本均无碰撞或物理保护。**特征识别改善不等于导航成功改善。** 当前最明确的下一步是完成新动作actor与环境适配，进行短程精细对齐PPO，再用独立场景验证，不能直接继续旧12动作的长训练。
