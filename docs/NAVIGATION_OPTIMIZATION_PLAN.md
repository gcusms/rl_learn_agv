# 安全、效率、突发避障与边缘部署计划

日期：2026-10-11。当前工程以学习定位、神经路线网络和 PPO 速度策略为正常导航链路。传统导航仅作为独立基准；必要的急停、指令超时和限速保护不算模型能力。

## 优先级与边界

优化顺序是安全和成功到达，然后在可行路线中降低到达时间与路程，最后在不降低前两者的情况下压缩推理成本。动态障碍的未来不可完全观测，不能保证任意环境的全局最短、最快或绝对最优；必须报告具体分布和相同协议下的结果。静态最短与动态最短不能混用。

当前前进 0.2m/s、倒车 0.08m/s、角速度 0.5rad/s、控制周期 200ms、220 束/219.44° 激光视野保持。没有真实测量前不提升速度上限，不假设编码器已经存在。当前模拟里程计取实际速度加噪声，与实车指令积分里程计有差距，后续扰动训练必须覆盖。

## 验收目标（拟定，未达到）

独立冻结 200 个任务：静态60、慢速动态50、遮挡/丢帧30、定位扰动30、未参与训练布局30。另建开发验证集；最终验收集不用于反复选模型。12任务开发清单只能定位问题，不得当成泛化能力证明。

- 静态安全到达率目标 ≥98%；动态初期目标 ≥90%。到达但接触/防穿透回退不能算安全成功。
- 最终报告碰撞、超时、错误到达、最小净空、等待时间、路线切换和安全保护触发，不只汇总成功率。
- 静态实际路长与离线膨胀栅格参考路长同时报告，参考有网格/平滑误差，并非连续空间最优下界。
- 同条件 TEB 比较成功率、安全、完成时间、路长和平滑性；不通过单纯降低安全间距获取更好时间。
- 定位初步目标：正常已知地图任务 P95 平面误差 ≤0.10m；异常任务无未检测的持续失控。失效恢复阈值依据标定和净空调整，尚未保证全局重定位。
- Orin Nano 初始设计预算：控制仍为5Hz，路由按需要约2.5Hz；导航推理整链 P99 <100ms，模型/地图运行进程内存目标 <1GiB。预算需实际板端确认；TOPS不能直接换算这里的小网络、Python几何和CPU预处理延迟。

## 第一轮实现

1. 续训入口允许选择已有父策略、组件、离线数据、采样/批量/KL约束、种子，并拒绝覆盖已有输出。
2. 并行扩展时按采样量缩放辅助动作训练批数，避免12环境悄然把每条样本的辅助训练量降至原来的1/3。PPO 的 KL 约束不约束额外辅助更新本身，需通过独立评估监测退化。
3. 路由缓存只缓存完全相同的网络输入；静态可见性缓存只用于不可变静态地图。动态占据逐次检查。
4. 激光无有效回波时不调用定位打分器产生伪纠偏；保留里程计传播，增加不确定性并暴露诊断字段。这不是完整定位失效恢复。
5. 安全训练遇接触/防穿透回退终止并给负奖励，不允许同一步到达奖励抵消安全失败。
6. 固定12任务评估当前10万步策略；同一运行代码上追加2.4万步诊断训练并复评。原策略不替换，达标前候选保留为实验。

第一组候选复评仍为12/12安全到达，但平均用时由62.75秒增至64.93秒，平均路程8.790米至8.781米，未达到效率改进目标。离线4096条动作样本上，前进标签对应的模型平均前进动作由0.711降至0.688，而标签平均为0.693；与辅助拟合使速度趋于较慢标签的解释一致，但不能单凭相关性证明全部原因。第二组独立候选从原模型出发，关闭辅助动作更新、增加每200ms步0.04时间成本；这同时改变两个因素，是效率方案的联合试验，不是单因素因果验证。两组都保持实车限速和安全终止。

第二组已完成24,000步训练与相同12任务复评：12/12安全到达，平均61.68秒（比原模型快1.70%），平均8.794米（增加0.04%）。通过开发筛选但不是正式部署验收。两组累计48,000步，默认策略没有替换，下一阶段优先扩大诊断与改善路线，不直接宣称达到最短路径或最优动态决策。

## 突发障碍与定位专项设计

突然出现的测试必须在仿真物理上可避免：出现距离应考虑传感器/控制延迟、制动距离、机器人尺寸和障碍运动，不能只按固定距离。基础关系是 `d_stop = v * delay + v² / (2 * a_brake)`，其中速度、延迟和有效制动加速度需要实测/保守随机化；障碍靠近速度与定位/预测误差另加裕量。无法避免的外物主动冲撞单列，但不删除原始接触统计。

未来路线选择比较安全等待、短绕行和较长绕行的完成时间，不能固定“见障碍就绕”或“见障碍就停”。训练输入应包含扫描时间/有效性、车速和连续扫描的运动线索，未来占据标签只在训练时使用仿真真值，运行时只能由传感器估计。未观测空间不能假设自由，预测不确定性随遮挡时长增长。

定位任务需要分开检验局部跟踪、失效检测和重定位。当前无回波修复只解决第一类的伪纠偏；置信度校准、多假设扩展、重复房间的错误匹配和长距离重定位仍是后续工作。评估必须加入轮速/指令里程计偏差和扫描缺失，避免仅用精确仿真里程计获得好结果。

### 2026-10-11 第二轮实际执行

已完成共享纯传感器导航核心、TorchScript actor 导出、已知地图折线简化、低匹配支持时扩大位姿候选的实验恢复，以及 40 项开发测试。正常运动指令仍由 PPO 输出；路线网络和定位网络采用监督训练，折线简化是显式几何处理，不能称为全部模块端到端强化学习。没有 Nav2/A* 正常控制接管。

## 第三轮续评与下一步门槛

两次各30,000步动态诊断已完成，默认模型未替换。普通原始动作评估均40/40安全，但包含保护的导出执行链分别30/31：原始动作续训有1次碰撞；一致执行链续训无碰撞但1次超时。因此不能直接扩为百万步或把普通评估的成功率当成部署效果。

当前新增的是可选 `guarded` 训练模式：训练和部署共用传感器导航核心、确定性的指令保护变换、已执行动作历史；PPO记录原提议动作的概率，用实际执行后的收益学习，并惩罚保护介入。这仍是PPO，但保护本身不是学习能力。默认 `raw` 模式继续直接执行模型动作，两个模式不能混称。
