# README 视频

仓库内的 docs/media/navigation-four-window.mp4 是原四窗口录制的压缩副本，完整 82.36 秒，1600 × 1254，25 fps，约 8.7 MB。采用 H.264 / yuv420p，MP4 播放索引置于数据之前（faststart），便于边下载边播放。

README 已配置预览图与视频文件链接。如果希望 GitHub README 中直接出现内嵌播放控件：上传仓库后，在 GitHub 网页编辑 README，将此 MP4 拖入编辑区域，保留 GitHub 生成的附件链接，再保存。附件地址需要 GitHub 实际上传后生成，不能用本地路径代替。
