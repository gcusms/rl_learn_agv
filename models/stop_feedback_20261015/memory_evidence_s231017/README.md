# 连续有限回波确认的记忆配置候选

这里只生成独立配置候选，新增训练0步；actor、定位器、路由器和方向停靠权重逐文件相同。bc4500与ppo1665分别对应两个原模型，不能相加其训练步数。

改变的是记忆点的空闲证据阈值：连续3个不同时间戳、间隔不超过0.4秒的有限回波，且三个相邻雷达束均穿过旧点至少3厘米，才可清除。3厘米是清除证据阈值，车体碰撞余量仍为4厘米。未知、遮挡、满量程和后方盲区不提供清除证据；不按时间删除点。

配置从初始化起生效，没有90/97.6/106秒等运行触发条件。此前接管时切换配置的单项收益，尚不能证明该候选完整闭环有效。所有manifest均为deployment_approved=false；未覆盖原模型或实车交付包。完整来源与哈希见VARIANTS.json。
