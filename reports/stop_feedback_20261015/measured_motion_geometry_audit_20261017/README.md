# 实际反馈速度与指令恒速几何的只读对照

当前原保护的激光车体检查使用指令恒速轨迹；仿真底盘通过20倍速度误差和受限加速度施力。两者的转向反向/制动过程可能不同。本实验先验证实际记录，不能预设改用有限响应就会成功。

使用当前106秒失败、原转向失败及原96秒成功三条完整记录。首先按实际执行原因从第一帧重建原记忆，独立复核原许可/激光拒绝类别；随后仅在固定记录上比较原指令轨迹与使用反馈速度的有限响应轨迹。车体、4厘米余量、记忆、未知/盲区、动作和物理记录不改变；对照通过不授权任何新动作，不修改正在运行的逐帧搜索。

还对全部实际执行的相邻帧比较下一时刻真实车体位移/转角，用真实位姿仅评价误差。有限响应预测只用当时反馈速度与实际命令；未执行动作的假设不与实际未来混淆。该响应近似来自已声明仿真参数，不等于实车标定，也不构成新的安全证明。

0.10核软件预算、650MiB硬内存，不加载神经或物理模型。结果以RESULTS.json为准。若发现差异，仍需独立闭环、从初始化、匹配观测语义、原全部保留/困难恢复及冻结配对要求，不能直接改保护或发布。
