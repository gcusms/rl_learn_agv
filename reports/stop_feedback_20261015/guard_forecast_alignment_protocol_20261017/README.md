# 短时保护与长期风险输入对齐：迁移候选与串行验证

这项工作修复一个明确的输入不一致：传感器支持的短时保护已预测接触时，旧长期风险特征可能仍为零。**v2迁移候选已完成540次监督更新，尚无新PPO或整体导航收益结论；28项完整保留验证已全部通过。**

在已完成40个物理回合的8,367帧记录中，770帧出现停车动作的短时接触风险未进入旧长期特征，其中682帧旧长期预测有效标志为真、464帧只剩停车合法。短时保护原本就计算停车动作；问题不是“没有计算停车风险”，而是两条预测链的轨迹保留、年龄与不确定性处理不同。记录审计只说明特征不一致，不能由此认定碰撞不可避免或所有零速决策都错误。

## 修复语义

新版本为 `long_action_risk_history_v2_guard_lower_bound`。每个动作沿用旧5秒长期风险，并与同一传感器时刻、具有轨迹证据的短时接触预测取更保守的值。接触时间按原长期风险的同一5.2秒分母归一化；例如短时接触0.7秒，对应风险约0.8654。不是把短时与长期的原始分数直接比较。

三帧物理时间仍为0.4、0.2、0秒；缺失的历史采样保留缺失，不拿未来数据补齐。有效标志只表示存在传感器支持的预测，风险零或预测缺失不授权前进。无轨迹、错误时间戳或失效扫描不会凭空生成有效预测。

625维总长度保持不变，只有439:481的风险历史语义改变；其他特征、12个动作、原动作掩码、停车许可、车体与4厘米碰撞余量保持原规则。没有额外神经网络推理，也没有运行时间或板端性能收益实测。

原生实现为 [aligned_risk_observation.py](../../../training/neural_navigation/aligned_risk_observation.py) 与 [aligned_release_runtime.py](../../../training/neural_navigation/aligned_release_runtime.py)。独立运行时会拒绝旧版本bundle，避免把新语义直接交给旧模型。它已按完整运行时名称显式注册，并支持相同状态的恢复评估；旧版本名称仍解析到原类，未知维数/名称不猜测加载。旧部署不自动改变。
