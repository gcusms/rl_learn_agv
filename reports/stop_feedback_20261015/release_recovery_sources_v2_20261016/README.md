# 等待后恢复：追加来源与数据边界

本批数据复用已完成的安全闭环轨迹，没有新增物理仿真或 PPO。保留原 1,790 条数据的数组前缀，再加入 719 条决策，共 **2,509 条、1,959 个不同完整观测**。数据散列及逐条来源见 [RESULTS.json](RESULTS.json)。

新增来源为 `early_yield_sensor_holdout_05_0`、`long_risk_sensor_02_0`、`long_risk_sensor_02_1`、`long_risk_sensor_05_0`。四条完整轨迹均已独立评分为物理到达、无碰撞、无保护投影及无假到达；新增决策全部由当时的模型生成。原数据仍包含已标明的离线教师来源，不能把整个数据集描述为纯模型自采样。

完整轨迹共 723 帧。每条轨迹最后一帧是到达停车，恢复分支不启用，其中三帧的候选动作与最终到达停车命令不同。初次构建因把这两种动作混为一谈而拒绝了数据。修正后的构建器保留完整安全证据，明确排除四个不参与恢复训练的末帧，**不把最终停车命令改写成策略采样标签**；719 条入选决策的策略选择与实际执行逐条一致。

原来的四个“新噪声”条件已用于诊断，其中三个成功条件本次进入训练，因此这批条件现在属于开发集。失败的 `long_risk_sensor_05_1` 未作为正示范进入数据，失败轨迹及散列保留。不可继续把原四个条件称为独立测试。

训练分支启用的数据有 2,025 条：563 条停车，1,462 条运动。等待至少 2 秒后恢复运动的样本只有 **23 条、17 个不同输入**；增加总帧数没有消除恢复样本稀缺问题。

| 损失分配 | 停车 | 常态运动 | 等待后恢复运动 |
|---|---:|---:|---:|
| 原 stop/move 模式 | 50% | 与恢复共同分配另 50% | 依样本数分配 |
| 本次可选 phase 模式 | 50% | 25% | 25% |

phase 模式在各阶段内按完全相同的模型输入去重分配权重；两种模式都没有删除停车样本、取消停止动作或插入运动命令。权重规则本身不证明动作安全，安全来源准入仍由完整物理轨迹和执行检查提供。

本批构建平均约 0.15 核，峰值约 505 MiB。代码见 `training/experiments/build_release_recovery_sources.py`，终点标签检查见 `test_release_recovery_sources.py`；配对拟合见 [下一步结果](../release_phase_fit_20261016/README.md)。
