# v2 PPO 动态01耗时退化：原因分解

上一轮已结束：固定28项全部安全，但已知动态01耗时从BC4500的34.6秒增至53.4秒，超过原20%单项退化上限。本诊断使用其实际记录，不增加物理回合或修改运行时。

| 耗时类别 | 新增时间 |
|---|---:|
| 所有运动动作被否决，仅允许停车 | 12.8秒 |
| 仍有运动动作，策略选择停车 | 5.2秒 |
| 非零动作执行时间 | 0.8秒 |
| 合计 | 18.8秒 |

新旧轨迹在6.6秒首次选择不同动作：BC4500选择动作11，v2迁移模型与追加PPO1993模型均选择动作6。此前的实际扫描、输入里程计、反馈速度、车体和障碍物物理状态、路由及动作掩码相同；625维观测只有439:481的历史预测语义不同，不能声称整个网络输入相同。这说明该分歧在PPO之前的输入适配阶段已经存在，不应全部归因于PPO。

BC4500及PPO1993分别使用各自实际合同的记录进行模型重放，全部174/268帧动作准确复现。迁移模型仅在v2记录状态上作影子推断，不代表它执行了一条完整物理轨迹。新轨迹的最大定位误差约6.7毫米、路径终点误差近零，不支持把此例主要归因于定位或终点错误。

## 动态预测与候选算法

原预测器在四条记录的565帧、所有有限接触时间和有效轨迹数量上准确复现，接触时间误差为0。新轨迹连续13.2～26.6秒的68帧只剩停车，运动动作全部由动态预测否决。

轮廓配准与配准残差替代方案在固定新轨迹上将预测层仅停车帧82→18，但这只是影子计算。在本项目2026-10-15的历史闭环中，该方案在两项已知任务都碰撞，因而没有采用。不能以减少拦截次数推断安全提升，也不能直接换成此方案启动PPO。

原累计轮廓预测在新轨迹20秒时仍使用约9.6秒前的速度锚点，26.6秒时约16.2秒；新轮廓测量新鲜，不等于旧速度估计新鲜。该证据支持继续检查速度更新与未知假设，尚不证明每次拒绝都是误报。

首次诊断的辅助圆形障碍距离标签误把世界坐标与里程计坐标直接比较，相关字段不能使用；已单独保留[坐标纠正与重放](CIRCLE_FRAME_CORRECTION.json)，先将世界标注变换到真实车体，再变换到输入里程计。该标签从未送入模型、预测器或训练；接触时间、动作复现和耗时分解不受影响。
