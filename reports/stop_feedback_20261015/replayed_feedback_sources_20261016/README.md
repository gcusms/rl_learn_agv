# 旧恢复分支支持范围：拒绝训练

3252 条拟加入样本中，8 条安全参考动作位于当前头的可训练范围外，同时与冻结基础策略不同。继续拟合无法改变这些动作，因此没有写出训练集，也没有创建新模型。

这些状态发生在停止后已经重新运动的绕行过程中。雷达最小距离为 0.32～0.69 米；预测、扫描均有效且存在可行动作。只根据近期动态轨迹或上帧等待启用恢复头，会遗漏这类近障运动状态。换用两个旧基础模型也仍有 2～3 条原样本不兼容，未简单替换。

见 [拒绝结果](RESULTS.json)、[逐状态近障检查](../recovery_support_audit_20261016/RESULTS.json)、[基础策略兼容性](../feedback_parent_compatibility_20261016/RESULTS.json)。新实验只扩大学习范围，未改变运动许可。
