# 晚恢复：原许可下的三个转向试验

530 帧原始物理前缀只重放一次，再对同一快照分支。两次各 10 帧续跑的物理状态、雷达、里程计、625 维观测、掩码、动作和执行均精确一致；此前独立运行状态复制也通过两次 15 帧验证。

试验保留原车体、4 cm 安全余量和原始动作许可。只有实时掩码允许纯右转时才转向，转角按实际输入里程计累计，随后恢复冻结候选；无时间触发、强制非法动作或新增倒车。

|---:|---|---|---:|---:|

| 0.3 | 否 | 0/0 | 0.0685 | 115/122 |
| 0.6 | 否 | 0/0 | 0.0593 | 103/119 |

三个试验均耗尽原 140 秒任务期限，未形成完整安全成功来源。转向会改变后续许可，多数后缀转为仅停车可选；不能把这些停车都当作模型主动拒绝，也不能把某一瞬间动作合法当成完整恢复可行。记录输入中的冻结基础策略在新候选主动等待处也没有运动替代，暂不追加相同基础策略接管试验。

共 1,070 个物理步（含初始化与精确复制检查），约 383.0 秒、134.09 CPU 秒，平均 0.35 核，峰值 RSS 2,772.8 MiB；102 项固定输入哈希核验通过。新增训练与 PPO 0。失败试验没有准入为成功标签。
