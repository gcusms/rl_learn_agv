# 有动作可选却持续停车：分支与采样诊断

本轮新增只读诊断，没有修改部署模型、运行时、安全参数或正在进行的两组 PPO。物理专项仍由既有辅助任务串行完成。本目录的离线预测不计为新的导航回合或 PPO 步数。

## 已确定的机制

在近场转向诊断包的 106 秒历史之后，完整自主接管 **170 帧全部有停止、原地右转、微前进右转可选，模型仍停车 34 秒并超时**。定位 P95 约 5.2 mm，最终距目标约 1.80 m。这只是一条已用开发历史，不是独立泛化成绩。

对这 170 条实际观测进行同权重回放，选出的停止动作与原物理记录逐帧一致。观测和掩码一致、扫描与预测输入有效，**170/170 帧可训练恢复分支都启用**。参考 BC 的停止概率最低为 0.9999988；新放开的原地右转概率中位数约 1.45e-15。冻结基础网络本身的停止 logit 比最佳运动高约 18.44，恢复分支的修正仍未使运动胜出。因此这里的直接障碍是动作分布极端偏向停止。

两组 2k PPO 和新增 2,355 标签 BC 在相同记录上也预测停止 170/170；这些是跨模型离线预测，不能称为它们在修改保护后的独立导航结果。该诊断包改变了近场旋转许可，仅供专项研究，标准模型和两组 PPO 的保护保持原样。

另一种停滞出现在 2k 对照的完整 W11 任务：202 帧实际停车且有运动动作可选，全部处于可训练分支，停止概率中位数约 0.660。原参考 BC 在这些同输入状态上有 141 帧会选左侧微前进转弯；保留约束组有 63 帧会选该动作。这里存在 PPO 更新后的决策边界退化，和前述极端饱和的晚期状态不同。跨模型预测依旧不能证明转向后一定能到达。

参考 BC 原完整 W11 安全到达记录也有一帧合法停车，说明“有可选动作就必须运动”会误伤合理停车。需要完整后续任务结果来决定何种等待应被纠正。

## 实际训练覆盖

| 数据 | 样本数 | 此前合法等待至少 2 秒且仍有运动动作的样本 |
|---|---:|---:|
| 原参考 BC 示范 | 2,089 | 0 |
| 新增路线后的 BC 示范 | 2,355 | 0 |
| 2k 对照实际 PPO 采样 | 2,000 | 0 |
| 2k 保留约束实际 PPO 采样 | 2,000 | 66 个可训练状态，均采样停止 |

约束组 66 个状态全部来自 `physical_prefix_w11_training_stall_t90`。另有一帧等待达到 2 秒但不可训练，未混入 66。初始化物理历史不计为 PPO 更新样本，不能用几百帧的前缀长度冒充长等待学习量。两组均未启用已有的长等待探索损失。

现有模型不是没有任何转向示范：原数据含 59 条原地右转，新数据为 62 条；缺的是上述长等待恢复状态下的有效经验。只增加原课程步数，或只补更早绕行路线，不能保证填补这个缺口。只启用探索损失也需要课程确实到达它的启用状态。

证据为 [RESULTS.json](RESULTS.json)、[TRAINING_COVERAGE.json](TRAINING_COVERAGE.json) 和逐帧概率 [predictions.npz](predictions.npz)。初稿输出及源文件单独保留；当前结果直接累加运动动作概率，避免 float32 的 `1-p_stop` 抵消极小概率，并增加同权重决策一致性检查。

## 接下来的证据与改动条件

1. 等待近场合法右转的完整物理试探，检查实际执行、接触、保护、后续进展和最终到达。几何许可和短时间挪动都不能代替恢复成功。如果没有帮助，就不把这个动作标成成功示范，也不默认开启该选项。
2. 现有辅助队列接着复现约束组训练碰撞，并执行已固定的早期示范候选六回合与参考三回合，区分随机危险分支、较早绕行改善和旧动作选择退化。
3. 如完整试探证实某种恢复有效，再补充相同扫描、掩码语义与完整历史下的运动和必要等待样本，并安排对应的实际 PPO 状态覆盖；模型单独闭环验证，不使用定时教师接管。
4. 如测试已有可行恢复仍不能学会，再单独比较已实现的长等待合法动作先验损失。该训练损失保留停止和原掩码，不能把它当作增加一个“等待后强制前进”的运行时规则。
5. 无论哪种改动，都须保留原 14 项、六项方向停靠，检查新增碰撞、假到达及已知 W11 / `localization_nav_33` 退化，另完成固定额外条件。等待减少不能抵消安全或正常任务退化。

新增完整 2k 对照的 W11 三个历史恢复均超时，其中 90 秒历史原 BC 可以到达。该结果和完整 18 项中的 17 次到达必须同时报告，不能仅按到达总数选模型。完整两组 35 行配对评估仍在执行，不自动增加训练或替换模型。

本轮读盘及推理分别限制约 0.05 核；推理审计峰值约 669 MiB，训练覆盖审计约 46 MiB。没有创建额外物理环境。
