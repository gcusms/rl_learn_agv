# 原106秒恢复的条件诊断

这里只准备离线教师可行性搜索，不是部署控制器，也不是强化学习成功记录。当前验证若在其他任务失败，或106秒任务已通过，都不运行搜索。

`launch_when_ready.py`由临时用户计时器短暂执行。只有本轮物理验证、当前权重的神经检查和独立固定28项复核全部结束，且本轮确实在原106秒任务失败时，才启动`run.py`。等待时只用标准库并立即退出，避免阻塞神经检查的串行条件；依赖重启、失败或中断不会自动重跑。

搜索严格恢复当前失败记录的原530帧初始化，保持原140秒截止、12动作、车体、4厘米余量、雷达、盲区、未知区域、动力学、记忆和定位/路由模型。每个分支都使用实时扫描重新计算原动作许可。最多4,300个物理步、3条保留分支、单次连续动作不超过3帧；另保留等待分支。使用真值的评分仅限离线搜索，不进入策略输入。

候选完整到达后还必须从同一快照逐帧重放，确认原动作许可、实际物理到达及安全。搜索失败不能证明任务不可行；找到教师也不能计为模型成功、不能自动纳入训练，更不能豁免原97.6秒恢复、96秒既有成功或后续冻结8组配对。

新模型目录和原部署均保持。该诊断资源上限为单线程、平均0.35核、3GiB硬内存、Nice19，与其他模型/仿真串行。实际是否执行、是否找到完整安全教师，以`TRIGGER_STATUS.json`和输出目录的`RESULTS.json`为准。
