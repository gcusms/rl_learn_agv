# 已知碰撞的传感器路由重放

目标保持为解决实际停车原因输入和有安全动作却持续不尝试的问题。最新模型固定28项保留，但动态障碍叠加丢帧任务仍碰撞；不能通过扩大训练或减小车体、安全余量跳过该失败。

新的记忆证据配置对照已经终止：同一96秒状态下，原配置接管后36.4秒到达，修改后44秒仍超时。原成功丢失，修改不采用，余下对照未运行。

本诊断不运行物理环境，而是重放碰撞案例保存的83帧原始扫描、实际输入里程计、反馈速度和时间。首先逐帧核对625维观测、动作许可、策略选择、实际命令、定位及路由诊断；不满足一致性时停止，不能继续归因。

每次神经路由重算时，读取当次实际输入对应的Q场，分别检查静态图、测量占据、预测占据下的连通性和贪心解码结束原因。独立图遍历只用于解释，不进入模型输入或运行时。现有有界神经解码器仅在复制的对象上做影子检查，不替换重放路线或动作。影子得到完整路线也不能称闭环修复成功。

下一步依据实际结果决定是修正地图/预测问题，还是验证神经解码修复。任何候选仍须原固定28项、已知完整任务、97.6/106秒困难恢复与条件预留种子要求；父模型、车体、4厘米余量、动作集合及原部署保留。单个任务、0.35核平均软件预算和3GiB硬内存限制。
