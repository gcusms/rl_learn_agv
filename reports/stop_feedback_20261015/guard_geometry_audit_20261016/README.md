# 停滞状态下的激光几何掩码核对

这是离线回放，没有新增仿真训练、执行动作或修改运行中的保护。

`replay.py` 用原始雷达、连续里程计和记录的地图位姿重新建立近场记忆，再调用当前保护的几何检查。已允许的动作必须仍通过，原有激光几何拒绝必须可复现；不重跑动态预测，也不会将动态预测的拒绝算成已解除。`PLAN.json` 固定输入，`RESULTS.json` 保存逐帧检查与最近障碍点。

W11 的 106～107.8 秒共 10 帧，原始动作集均为 `[0, 9]`。开启已有的原地转向脱离选项时，10 帧的原地右转（动作 5）通过几何检查。该选项只对起始间距为正、旋转过程不进一步侵入初始间距、结束时受限障碍点间距至少增加 5 mm 的候选生效，静态地图车体检查仍在。它会改变动作许可，不能当成原保护下的成绩。

106 秒最近的记忆点距车体约 4.09 cm，含年龄不确定性的要求为 4.56 cm；当前雷达最近点约 5.23 cm。另一条困难轨迹的十个检查帧中，八帧也存在这一差异。微前进右转诊断后的十帧中只有三帧出现差异，说明一个动作刚开始合法不代表后续能连续执行。

没有从本检查得出完整脱困、安全或泛化结论。完整物理验证的单独方案见 `../rotation_escape_t106_protocol_20261016/README.md`。旧 300 维模型曾在同类选项下五例全部失败，已在新方案中保留，避免将旧选项当作未经尝试的万能修复。
