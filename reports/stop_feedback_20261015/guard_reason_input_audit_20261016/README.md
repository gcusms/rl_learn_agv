# 当前拒绝原因是否实际影响了恢复网络

同一批已保存的 625 维输入，比较原 312 维头、新 408 维头，以及仅将新增投影输入归零的离线对照。父模型输出、旧特征、历史、掩码、感知、学习启用条件均保持相同；没有执行反事实动作，也没有生成新标签。

106 秒失败轨迹的接管后 170 帧：原模型全选停止；新模型 165 帧选动作 9、5 帧停止。关闭新增投影后为 168 帧停止、2 帧动作 9，相比新头有 163 帧改变。所有动作都在当帧掩码内，说明新增当前原因已被学习使用。

这不是新的物理成功：输入来自原模型停着不动的轨迹，新模型一旦运动就会遇到不同后续输入，可能仍被卡住。原 95/90 秒来源上离线动作完全保留，额外等待来源上有 2 帧动作不同；这些也不能代替闭环回归。拟合 3,250/3,252，部署准入仍失败。

六条轨迹逐项结果、完整输入哈希和约 0.03 核资源记录见 [RESULTS.json](RESULTS.json)。后续只做单例隔离物理诊断，原实车模型保留。
