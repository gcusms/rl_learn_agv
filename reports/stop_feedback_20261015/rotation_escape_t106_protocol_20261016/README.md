# 原地转向掩码专项验证

这是新的诊断实验，未合入部署包，也未改变正在运行的两组 PPO。

离线几何回放发现：W11 的 106～107.8 秒，10 帧原掩码均只允许停止和右侧微前进转弯；启用已有的 `clearance_increasing_rotation` 后，原地右转也通过几何检查。近场记忆的一个点距车体约 4.09 cm，而含观测年龄不确定性的要求为 4.56 cm。例外允许的是整个旋转中不再减小初始间距、末端间距至少增加 5 mm 的动作，仍检查静态车体及动态预测。没有缩小车体或 4 cm 固定余量。

这只是几何可行性。旧 300 维模型启用同一选项的五例评估为 0/5 到达、三次超时、两次碰撞，不能直接把该选项当作已验证的修复；旧结果保存于 `LEGACY_NEGATIVE_EVIDENCE.json`。

本实验固定 2,089 标签 BC 模型的全部权重、原 106 秒传感器/动作历史及同一物理任务，只在单独诊断包中启用此选项。先测试完整的模型自主接管。若仍失败且没有碰撞、物理保护或假到达，再诊断性地在 106～109.2 秒请求原动作表中的原地右转；仅在新掩码允许时执行，否则使用模型原动作，然后继续到到达或超时。定时窗口不属于模型能力，也不用于实车控制。

等待 `PLAN.json` 指定的旧辅助评估 invocation 成功结束、24 行配对结果及汇总完整后，才复用它的 0.15 核软预算。主 PPO 仍为 0.35 核，不增加同时运行的辅助仿真数量。输出与状态分别为 `RESULTS.json`、`STATUS.json`。

只有完整物理结果能判断该候选动作是否有用。即便诊断成功，仍需要对应掩码下的训练及原成功任务回归，才能考虑保留；不会自动发布或替换旧模型。
