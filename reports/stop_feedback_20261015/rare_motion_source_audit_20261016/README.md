# 已有成功参考中是否存在稀少动作组合

对固定协议中的成功参考去重，核对实际轨迹哈希、实体到达、零碰撞、零假到达、零保护干预和零超时。仅检查模型接管后、感知有效且离目标较远的片段，初始化前缀不算学习样本。

37 条完整安全轨迹中，没有找到“只有动作 0/9 合法、执行动作 9”的片段。所有至多两个运动动作合法的状态中，动作 9 也只有 1 帧，来自已知的 95 秒安全恢复；它并不等同于 106 秒困境的成功恢复。

这比仅检查 3,252 条当前训练标签更广，支持稀少约束组合缺少完整成功经验的判断，但不能推导该状态不可达，也不能把失败的动作试探作为正例。若未来从这些参考加入数据，相关任务应明确记为训练/开发回归，不能继续称其为未见测试。

完整逐轨迹计数、哈希和复现入口见 [RESULTS.json](RESULTS.json)、[audit.py](audit.py)。此审计不训练、不运行新仿真，也未自动将任何样本纳入训练。
