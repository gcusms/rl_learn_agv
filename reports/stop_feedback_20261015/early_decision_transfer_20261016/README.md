# 提前决策的可选训练数据

已完成数据审核，没有训练新网络，也没有改当前的 PPO 对照、保护或部署模型。

来源为旧 8k PPO 已完成的两条安全路线：`recovery_holdout_00` 在 44.4 秒到达、`recovery_holdout_01` 在 38.4 秒到达，均无碰撞、物理保护替代或假到达。它们是多次使用的开发任务；若采用本数据，之后不能称这两条任务为未见测试或独立 holdout。原始报告及轨迹哈希保存在 `PLAN.json` 与 `sources/RESULTS.json`，没有重新执行或增加成功次数。

`prepare.py` 调用原训练数据审核入口，检查完整物理结果、原始轨迹哈希、动作许可、实际执行一致性、观测转换及可训练范围，并与已验证的 2,089 标签数据逐项比较。保留原数据及其中 37 条合理停车标签，新增 266 条：248 条运动、18 条停车，总计 2,355 条。未发现相同观测和掩码对应不同标签的精确冲突。

在新增的传感器状态上，当前 BC 有 7 条选择停止、而来源 PPO 选择运动并最终安全到达；另有 70 条运动方向/速度选择不同。最低目标动作概率约为 `6.75e-9`。这说明存在具体、合法的监督候选，不能据此宣布新模型已经学会导航。

`candidate_demonstrations.npz` 只包含观测、原掩码和动作标签。仿真真值只用于原轨迹的安全结果检查，没有加入策略输入；没有定时教师或在线规划器代替 actor 决策。

当前两组 PPO 和转向几何专项仍按原计划执行。先根据其完整结果选择下一项改动，再决定是否在同一初始化、相同监督更新预算下采用这批新数据；目前 `training_admitted=false`。若采用，应同时保留原正常任务和方向停靠，增加新的开发外验证任务，分别报告训练任务重现与额外条件表现，不能只发布这两条已加入训练的路线。
