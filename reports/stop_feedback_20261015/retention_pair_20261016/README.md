# 两组同初始化 PPO 对照

2026-10-16 06:31 启动，实验独立于 GitHub 的 `work` 固定交接快照。前一目标轮已核对远程快照并确认两个原机任务仍运行，属于有实际进程依据的等待；本轮新增了转向几何诊断及排队验证。

目标是检验追加 PPO 时能否保留已学到的可行运动和合理停车，进而减少存在可行动作时的等待。两组从同一份 2,089 标签、800 次 BC 更新的网络及优化器出发，各执行 2,000 条实际物理 PPO 样本。第一组示范保留系数为 0，第二组为 0.05，每批平衡抽取停车与运动示范，共 128 条。两组均不启用长等待探索损失。原动作、观测、保护、奖励、课程与种子相同。

`INITIALIZATION_PARITY.json` 要求 BC 网络和优化器逐字节一致。示范约束不替换 PPO 采样动作、旧概率、掩码、奖励或执行历史，推理也不调用教师。两次独立 2k 不能合称一个 4k 模型，亦非原 8k 的精确断点续训。

`PLAN.json` 固定数据、模型与源码；`run.py` 在同一主任务内串行训练、审核及评估，预算 0.35 核软上限。每组训练结束需核对实际样本、更新数量、冻结组件及示范保留，再分别评估 18 项完整起点任务、两个原恢复历史、三个相关 W11 历史和 12 条额外条件。各组为 35 行，其中相关历史并非独立新场景。

实时状态为 `STATUS.json`，实际步数在对应模型的 `progress.json`，最终配对结果为 `RESULTS.json`。训练回合成功率不能代替独立闭环结果。不会仅凭总奖励或某个成功片段增加步数，也不会自动替换原部署模型。
