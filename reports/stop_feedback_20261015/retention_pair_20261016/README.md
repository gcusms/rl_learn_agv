# 两组同初始化 PPO 对照

2026-10-16 06:31 启动，实验独立于 GitHub 的 `work` 固定交接快照。前一目标轮已核对远程快照并确认两个原机任务仍运行，属于有实际进程依据的等待；本轮新增了转向几何诊断及排队验证。

目标是检验追加 PPO 时能否保留已学到的可行运动和合理停车，进而减少存在可行动作时的等待。两组从同一份 2,089 标签、800 次 BC 更新的网络及优化器出发，各执行 2,000 条实际物理 PPO 样本。第一组示范保留系数为 0，第二组为 0.05，每批平衡抽取停车与运动示范，共 128 条。两组均不启用长等待探索损失。原动作、观测、保护、奖励、课程与种子相同。

`INITIALIZATION_PARITY.json` 要求 BC 网络和优化器逐字节一致。示范约束不替换 PPO 采样动作、旧概率、掩码、奖励或执行历史，推理也不调用教师。两次独立 2k 不能合称一个 4k 模型，亦非原 8k 的精确断点续训。

`PLAN.json` 固定数据、模型与源码；`run.py` 在同一主任务内串行训练、审核及评估，预算 0.35 核软上限。每组训练结束需核对实际样本、更新数量、冻结组件及示范保留，再分别评估 18 项完整起点任务、两个原恢复历史、三个相关 W11 历史和 12 条额外条件。各组为 35 行，其中相关历史并非独立新场景。

实时状态为 `STATUS.json`，实际步数在对应模型的 `progress.json`，最终配对结果为 `RESULTS.json`。训练回合成功率不能代替独立闭环结果。不会仅凭总奖励或某个成功片段增加步数，也不会自动替换原部署模型。

1,750 步中期采样审计见 `CONTROL_SAMPLING_INTERIM_1750.json`：最后两个 250 步批次均只有停止合法，恢复 actor 可训练样本为 0。它们来自第二次早期避障历史接管，不能归类成“有动作却不尝试”。该历史共 857 条采样中有 634 条只允许停止；W11 90 秒历史的 59 条可训练恢复样本全部选择运动。此时训练尚未结束，不能据此宣布 2k 模型通过验收；它表明必须同时检查动作许可、冻结区域的随机采样与策略选择。

第一组 2,000 步已完成，最终模型为 `models/stop_feedback_20261015/w11_control2000_s231015/policy.zip`，SHA256 为 `7a8b576c1a29e357508cac3f473c2524bc2688c46f6f6f09be5a38d50fe88cb5`。1,060 帧物理初始化单独记录，没有计入 PPO。实际 889 条可训练恢复样本中 858 条运动、31 条停车，非零动作未被保护改写；791 条样本只允许停止。训练完成 8 回合，其中 7 次到达、0 碰撞，不代表独立验收。审核见 `../w11_control2000_audit_20261016/RESULTS.json`，学习分析见 `../w11_control2000_learning_20261016/RESULTS.json`。

在同一批训练观测上，最终网络相对 BC 有 194 条运动动作改变、两条运动变停车、没有停车变运动。去掉上一停车原因会改变十条贪心动作，但这属于可能偏离训练分布的离线敏感性检查，不能证明反馈已带来安全恢复。早期避障这类样本中，冻结区域的随机采样偏离次数为 0，因此该次停滞不能归因于冻结区域的随机探索；可训练分支的采样及更新仍需完整闭环对照。

第二组已通过网络和优化器初始化一致性检查。两组第一个 250 步实际 rollout 的观测、动作、掩码、旧概率、价值、奖励、GAE 和执行记录全部逐位相同，见 `FIRST_ROLLOUT_PARITY.json`。这证明示范保留的独立 RNG 未扰动第一次物理采样；第一次更新之后的数据可以随策略改变而分叉。
