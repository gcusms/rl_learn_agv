# 实际仿真输出的停车反馈核对

本目录核对的是v2候选在**实际物理闭环中发给模型的输入**，与先前仅转换旧数据的检查分开。来源报告以快照保存，已关闭的每份轨迹都验证SHA256；不会读取仍在写入的轨迹，也不修改正在运行的训练代码。

本次快照包含24个已经完成的开发回归任务、3,757帧，其中475帧属于恢复初始化，模型自主控制为3,282帧。其余尚未完成的回归不计入本次核对。

| 实际输入检查 | 结果 |
|---|---|
| 当前12个动作的拒绝原因与同帧动作许可 | 全部一致；停车始终允许单独处理 |
| 保护预测到的短时接触进入v2风险输入 | 全部满足风险下界，无遗漏 |
| 0.4/0.2/0秒的历史按传感器时间重建 | 与实际发出的42维历史逐元素一致 |
| 策略选择的动作与原动作许可 | 全部合法 |
| 非零执行命令与原12个动作 | 全部一致 |
| 初始化与模型控制 | 单独计数，未将公共前缀算成自主恢复 |

模型控制阶段有389帧出现支持的短时接触预测，251帧涉及停车动作本身。166帧只有停车可选，另有223帧在目标仍远、存在运动动作时选择停车。这两种情况现在能够从记录分开分析。

**223帧不等于223次错误停车。** 这些均来自最终安全到达的来源回归，合法动作也不保证能改善任务；等待可能是必要的。此核对只证明模型收到了对应反馈，不能证明网络正确利用它、困难106秒恢复已经成功，或新模型比原部署模型更安全。后续仍要以实际学习后的完整任务结果验收。

运行：`python3 reports/stop_feedback_20261015/guard_forecast_live_audit_20261017/audit.py`。本证据目录为一次性输出；再次核对应保留新快照，不能覆盖本次证据。无需ROS、CUDA或物理仿真，新增训练和物理步数均为0。
