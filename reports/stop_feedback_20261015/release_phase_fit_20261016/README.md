# 等待恢复：配对监督微调

两组拟合均已结束。使用相同的 2,509 条来源、随机种子 231016、初始风险分支和最多 300 次更新；唯一对照因素是损失分配与重复输入权重。没有新增 PPO 或物理交互训练。两组均保留冻结的定位器、路由器、基础 actor 和方向停靠分支。

| 模型 | 实际更新次数 | 来源标签正确 | 已记录失败回放改变的动作 |
|---|---:|---:|---:|
| `release_data_control300_s231016`：原 stop/move 权重 | 50 | 2,509/2,509 | 0/700 |
| `release_phase300_s231016`：阶段分配及输入去重权重 | 100 | 2,509/2,509 | 3/700 |

目录名中的 300 是更新上限。停止条件是在全部入选标签正确且停车、运动标签最低目标概率达到门槛后结束。两组优化器和随机状态均保存，导出模型与未导出模型的预测一致。具体损失、概率和模型 SHA256 见 [RESULTS.json](RESULTS.json)。

700 帧回放来自旧候选的失败轨迹，属于离线诊断。改变三帧不证明这些运动在新闭环中会安全执行，更不代表已恢复到达。两组在原失败等待帧上的停车概率中位数仍约 0.9998，因此不能把训练标签全对解释为等待问题已解决。

配对拟合平均约 0.35 核，峰值约 748 MiB。旧交付候选与两个归档包未替换。新增模型只用于 [有界闭环检查](../release_phase_validation_20261016/PLAN.json)：先在同一失败条件比较两组，安全到达的候选才进入旧成功条件保留及一个新噪声种子，最多四次仿真。新噪声种子在拟合后、闭环运行前冻结，仍是同一开发地图，不能称为未见地图泛化。

后续四次仿真已结束：阶段权重候选在已知失败、旧成功及新噪声条件分别以 90.6、36.8、33.0 秒安全到达；原权重对照仍在 140 秒超时。见[闭环结果](../release_phase_validation_20261016/README.md)。最长连续等待仍有 58.6 秒。常规导航、动态场景、旧恢复前缀、方向停靠和极窄条件等完整回归仍需检查。此处没有部署通过或定位更精准的结论。
