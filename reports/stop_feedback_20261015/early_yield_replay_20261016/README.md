# 提前让行诊断：区分必要停车与无效等待

2026-10-16。本项服务于“模型理解停车原因，并利用确实安全、有用的运动机会”的目标。四个旧碰撞案例的末段都已经停车，且只剩停止可选。因此，不能统一增加等待惩罚或强制执行某个合法微动；需要检查更早是否已有风险证据，以及停车位置是否合适。

本次从原雷达、里程计和速度输入完整回放 **237 帧**。保存的 439 维观测、原模型动作、实际执行命令及定位估计全部复现。没有新物理仿真、没有更新参数，也没有通过查看行人未来真值来发出动作。

预测只使用保护层已有的、连续里程计坐标系中的雷达运动轨迹，矩形车体和 4 cm 余量保持原值。对相同动作分别计算 2.4 秒和 5 秒预测，包含测得速度的一阶响应与轨迹速度误差。真值净距只在每步后单独评分，不输入预测器或策略。

| 旧失败任务 | 最早“前进预测有接触、当前位置停车预测无接触” | 2.4 秒预测接触时间 | 5 秒预测接触时间 | 该时刻独立真值净距 |
|---|---:|---:|---:|---:|
| condition_01 | 3.8 秒 | 无 | 3.2 秒后 | 0.750 米 |
| condition_02 | 3.6 秒 | 无 | 3.6 秒后 | 0.727 米 |
| condition_04 | 4.2 秒 | 2.4 秒后 | 2.4 秒后 | 0.633 米 |
| condition_05 | 5.0 秒 | 无 | 4.8 秒后 | 0.530 米 |

“无”只表示该近似预测未检出接触，不能当作安全证明。前三列风险条件不使用真值净距；最后一列也不是实际停车后的反事实结果。特别是 condition_04 在短时域已有信号，说明只延长时域不足以解释全部失败，策略如何利用现有风险同样需要补训和验证。

下一项是一个有界闭环可行性试验：原模型正常导航；当名义运动存在较长时域的接触预测、而停车未预测到接触时，离线教师只选择合法停止。在连续三帧有效动态观测确认运动预测恢复后，交回原模型。没有定时转向、强制前进、清空盲区记忆或降低保护。它排在当前回归之后，仅允许一个完整试验。

该试验即使成功，也只是完整安全示范来源；只有后续神经模型独立接管、正常任务回归及未用于拟合的条件通过，才说明学习有效。失败或部分轨迹不得作为正示范。

## 算法参考与适用边界

[Nav2 Collision Monitor](https://docs.nav2.org/jazzy/configuration_and_development/configuration_guide/core_servers/collision_monitor/configuring_collision_monitor_node/) 用当前机器人速度与传感器数据计算碰撞时间，并提供停止、减速等行为。这里借鉴碰撞时间和提前减速思路；本项目还需要预测障碍物运动及停车位置，不能把机器人停住等同于行人不会撞上它。

[Nav2 MPPI 配置说明](https://docs.nav2.org/rolling/configuration_and_development/configuration_guide/controller_plugins/mppi_controller/configuring_mppic/) 明确预测时域由时间步数和步长共同决定，并要求与可见地图范围及速度相配。本项目的 5 秒为待验证的诊断参数，未据此修改部署掩码，也不声称这会自动获得准确的行人未来轨迹。

上述迁移到本项目的设计是工程推断，待闭环数据验证。更长的恒速预测会积累速度、关联和轮廓误差，仍需防止误报导致长期停车。原观察维度、实车限制及原部署模型均未改变。
