# 保留强空闲证据，再增加连续有限回波确认

这是固定记录轨迹的只读实验，不是已部署内核、已训练模型或动作许可。它针对277项已复现检查所揭示的“当前扫描可通过、保留测量仍拒绝”问题。

此前被拒绝的三帧记忆配置替换了原来的清理条件，并在原96秒恢复中丢失成功。本实验保留原条件：同方向三束邻近有效有限回波的最小距离，超过旧测量距离10厘米时，仍立即按原规则清理；另外才加入“超过3厘米、连续3个不同时间扫描、帧间隔不超过0.4秒”的确认。每个确认绑定到具体测量点及其原采集时间，新的占据测量会重新开始确认。

6项[边界检查](EVIDENCE_CHECKS.json)要求：未满3帧不清理、无效扫描打断计数、过长间隔打断计数、原强证据立即清理、视野外测量保留，以及时间过去或扫描不可用均不能清理。所有车体、4厘米余量、老化不确定性、距离上限和容量规则均调用原实现。

逐帧重放原106秒失败、转向失败和原96秒成功三段数据，核对实验所保留的每个点是否都存在于原始记忆、坐标和采集时间是否一致，以及是否出现容量驱逐。抽查转向几何时，要求原已通过的检查不丢失。额外几何通过不等于实际安全动作，更不证明完整恢复、从初始化闭环或原能力保留。

该实验不清除未知、遮挡和盲区，也不凭时间删除近处障碍；只有实际有限空闲回波能够累积确认。3厘米和3帧是待验证参数，不能据此声称已适配实车噪声或可直接替换保护规则。

只有本组检查正常完成、并确实影响106秒相关几何限制，才启动[从初始化的物理诊断](../positive_free_physics_protocol_20261017/run.py)。任何记忆变更都必须重新记录其观测和掩码、通过独立新进程重放、策略训练以及原固定28项、已知完整任务、97.6/106/96与条件冻结8组要求，才有资格被采用。原模型和运行内核保持原样。
