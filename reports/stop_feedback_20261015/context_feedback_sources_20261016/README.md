# 传感器上下文恢复：训练来源准入

训练集 3,252 条：原 2,848 条逐字节保留，加 404 条旧学习策略完整安全恢复轨迹的受控后缀。失败轨迹不生成正标签，初始化指令及终端未执行的候选动作排除。所有标签合法且与记录执行一致。

学习支持范围在旧条件基础上，加入“最近雷达障碍小于 0.8 米、运动掩码受限、或当前保护预测提示风险”，仍要求感知/预测有效、目标距离大于 0.3 米、至少一个运动动作可选。8 条原不可训练目标全部纳入；可训练条目 2,656，剩余条目均与冻结基础策略一致。该规则参考项目已有 proactive recovery 的启用范围，仅决定哪个学习分支工作，不放行动作，也不要求最低速度。

动作集合、车体、4 cm 余量、未知区/盲区记忆、动态保护、停车能力和终端方向策略保留。总共仍只有 11 类出现动作标签（动作 8 无示范），不能声称所有动作都训练充分。
