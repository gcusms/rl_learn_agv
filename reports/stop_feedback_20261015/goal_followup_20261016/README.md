同一段 601 帧回放复现了观察、实际命令和定位估计，分别计算当前雷达与历史记忆的几何否决。两种限制都存在，例如 112 秒当前测得的最近车体净距仅约 3.45 厘米，低于 4 厘米保护余量；其他帧则由历史点限制转向。不能用清空记忆或强制转向概括解决。

按冻结仿真真值计算，原 106 秒位置在任意朝向下的几何净距下界只有 4.0556 厘米，超过保护余量约 0.56 毫米。这个离线分数不证明当前传感器允许转动，也不证明完整动态路径可达。仍需改善提前避开过小运动余量状态的决策，以及保留必要停车的安全恢复；没有证明严格不可达，也没有批准缩小余量。
