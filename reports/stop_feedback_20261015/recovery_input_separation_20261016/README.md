# 剩余恢复转向的输入与权重检查

剩余错误为新增完整安全参考来源的第 124.0 秒状态，目标动作 11、当前动作 1。没有发现相同头输入的冲突标签。最近的不同标签状态与其头输入欧氏差约 1.31，在当前风险/反馈、扫描、质量和目标运动特征均有差异；尚无证据需要修改观测合同。

原阶段分配中停车占总损失 0.5，普通运动和等待后恢复各占 0.25。普通运动含 1,689 种输入，而恢复只有 21 种输入；常见直行分到的运动损失大于纯左转和小弧转。该差异不是证明故障的充分条件，故仅做单因素对照。

新权重保持每个阶段总预算及精确重复输入的去重逻辑。两个运动阶段内，出现的动作类别各得相同份额。每条来源仍为正权重，全部原标签保留，停车样本的权重逐项不变，不在运行时选择动作。源数据、种子、初始化、312→32→32→12 网络、启用条件与最多 2,000 次更新均相同。

新检查与原检查共 17 项通过。拟合即使通过，也只允许进入独立物理回归；不能将标签准确率称为导航成功率。见 [输入距离与原权重](RESULTS.json)、[对照协议](../action_balanced_context_protocol_20261016/PLAN.json)。
