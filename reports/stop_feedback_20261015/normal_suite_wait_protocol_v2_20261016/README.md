# 正常导航保留与实际等待状态续行：配对实验

2026-10-16 23:50 北京时间：完整正常18项已全部通过安全与效率门槛，传感器5项、历史恢复3项及方向停靠2项也保留。三个晚期困难状态继续验证；新增PPO为0，原实车模型保留。机器可读进度见 [CURRENT.json](CURRENT.json)。

## 为什么需要本实验

上一 3,500 次监督更新候选恢复了 e7 的效率：上一 3k 的 58.6 秒、104 帧主动等待，变为 37.0 秒、1 帧。但动态任务 `independent_dynamic_000` 相对较早成功参考从 51.4 秒变为 79.2 秒，增加 54.1%；可运动却等待从 0 增至 194 帧。固定正常任务只测完 9/18，因效率门槛未通过停止扩大。其余已完成传感器、恢复和方向停靠均安全，不足以证明整体升级。

首次分叉发生在 8.6 秒：原始扫描、里程计、反馈速度、掩码、此前执行及共同 439 维输入完全相同，12 个动作均合法，较早参考向前，新候选停车（概率约 99.27%）。到 35 秒，停车概率约 99.998%，仍有 12 个合法动作。没有证据支持仅放宽安全约束；该任务存在模型过度等待。

## 这次改了什么

| 项目 | 内容与边界 |
|---|---|
| 原样保留 | 原 4,949 条观测、掩码和标签逐字节保留，安全停车标签不能丢失 |
| 正常能力覆盖 | 完整固定 18 项：8 项用当前候选已验证且效率合格的完整轨迹；10 项重建较早成功参考的完整 625 维传感器历史 |
| 历史重建 | 10 项共 803 帧，旧 439 维输入、动作掩码、选择及执行逐帧复现；仅据原始扫描、里程计、速度与时间，不输入未来或仿真真值 |
| 等待状态数据 | 从候选真实运行到 35 秒的等待状态继续物理仿真；冻结参考策略再用 26.4 秒安全到达，无碰撞、假到达或物理保护干预；133 帧完整后缀中 132 帧为有效训练决策 |
| 数据总量 | 正常保留集 7,246 条，含原 4,949 条；加入等待续行后共 7,378 条 |
| 配对变量 | 对照只训练正常保留集；实验组再训练这 132 条等待后安全续行。两组从相同 3,500 次检查点、Adam、随机数及损失出发，每组最多追加 1,000 次监督更新 |
| 训练类别 | 本步骤为监督模仿（BC），新增 PPO 0；两组不能相加为单个模型的训练次数 |
| 运行约束 | 625 维输入、12 动作、原车体和 4 cm 余量、雷达、动力学、掩码与保护一致；定位器、路由器和停靠部分冻结 |

35 秒后的安全续行证明该具体等待状态存在可行办法，并不代表新候选已经学会，更不证明晚期 106 秒状态已经解决。18 项均是开发/训练回归来源，重新拟合或复现不能算独立泛化成绩。

这类在学习器实际访问状态补充可验证标签的做法参考 [DAgger（Ross 等，2011）](https://proceedings.mlr.press/v15/ross11a.html) 对分布偏移的分析；论文不构成本项目的安全或效果保证。
