# 2026-10-16 雷达条件驱动的提前恢复示范

这是离线训练来源，**不是新模型的评估成绩**。在已知长等待条件中，上一阶段模型配合离线教师于 34.8 秒安全到达，路程 5.244 米，无碰撞、无物理保护干预。175 帧中教师仅选择了 2 帧替代动作，其余由参考模型执行。

教师在模型选择停止、存在合法运动、已有持续等待且当前及历史扫描支持安全运动时，结合当前路径点、有限响应运动预测选择已有合法动作。它不读未来帧、任务时钟或物理真值，不修改车体、动作掩码或保护余量。无效或未知观测不作为自由空间。7 项针对性功能检查已通过。

完整轨迹经过独立安全准入、逐帧教师输入重放后，排除最后一帧已结束的到达状态，新增 174 条训练决策。之前 2,509 条输入、掩码和标签逐字节保留。后续候选是否真正学会恢复，必须另做无教师闭环评估。
