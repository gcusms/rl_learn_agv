# 近场障碍记忆：组合空闲证据候选

本候选仅用于诊断，未接入默认运行时或当前PPO模型。它尝试同时保留原规则的即时强证据清除，并用连续弱证据清除过时的障碍点；不能由离线清除数量推断导航更安全或能够脱困。

## 证据规则

- 有限回波穿过旧点至少0.10米时，沿用原规则立即清除。
- 或者，连续3个不同时间戳、间隔不超过0.4秒，三个相邻有效回波均穿过旧点至少0.03米，才按重复证据清除。
- NaN、Inf、无回波、盲区和时间流逝均不构成空闲证据。新命中会重置对应的清除确认。
- 保留原坐标变换、距离范围、记忆不确定性和点数上限；先合并两种证据，再进行原最近点截断。车体轮廓和4厘米安全余量没有调整。

[12项实际检查](TEST_RESULTS.json)全部通过，包括立即清除、连续时间戳、未知中断、新命中、盲区、坐标、容量和影子探测不改写实时状态。
